# Drop-Desaster

Unterrichtsmaterial LF 7 (SoleStore / Sneaker-Drop).

## Systemtest – Anomalien

Interaktive Lernseite: Die Gruppen testen an drei Stationen Einfügen (Insert), Ändern (Update) und Löschen (Delete), erst in der alten Bestellliste, dann im neuen Tabellenmodell, und sammeln das Codewort.

- `systemtest/index.html` – die Lernseite (läuft ohne Server, einfach im Browser öffnen)
- `systemtest/sprachnachricht.mp3` – Sprachnachricht des Chefs für den Einstieg

Über GitHub Pages (Settings → Pages → Branch `main`) ist die Seite unter `…/drop-desaster/systemtest/` erreichbar.
